# Создание модов для RcCarsRe

[English](MODDING.md) | [Magyar](MODDING.hu.md) | **Русский** | [Polski](MODDING.pl.md)

RcCarsRe (пересобранный exe RC Cars) умеет загружать моды: файлы, которые заменяют собственные файлы игры, не трогая
папки игры. В оригинальной игре поддержки модов нет; это современная функция пересборки, которая включается
`RcCarsRe.ini [Modern] Mods=1` (по умолчанию). При `Mods=0` или без папки `mods` игра читает ровно те же файлы, что
и оригинал.

## Куда класть моды

Рядом с `RcCarsRe.exe`, в папку `mods`. Папка `mods` в собственной папке игры (например, `RCCars\mods` в копии из
Steam) тоже читается; exe никогда не пишет ни в одну из них.

```
RcCarsRe.exe
RcCarsRe.ini
mods\
    BetterSkins.zip            мод в виде zip-архива
    LoudReset\                 мод в виде обычной папки
        Sound\cp_reset.wav
```

Мод — это либо папка `mods\<имя>\`, либо архив `mods\<имя>.zip`. Внутри файлы лежат по собственным относительным
путям игры, так же как в папке игры (установка с DVD) или внутри `RCCars.pack` (выпуск в Steam):

| Что                             | Путь в моде (примеры)                                        |
|---------------------------------|--------------------------------------------------------------|
| текстуры                        | `Textures.1\sand.csi`, `Textures.2\...`, `Textures.3\...`    |
| текстуры для любого качества    | `Textures\sand.png` (вместо Textures.1, .2 и .3)             |
| звуки                           | `Sound\cp_reset.au`, `Sound\snd.ini`                         |
| музыка и интро                  | `Tracks\Dead_Track01.mp3`                                    |
| настройки                       | `Settings\...`                                               |
| трассы и база данных            | `RCCarsDB\...`, `RCCars.sb`                                  |
| язык, шрифты                    | `Language\Game\English.tbl`, `Language\English\...`         |
| машины, трафик, люди            | `CarProfiles\...`, `Profiles\...`                            |
| скрипты, сплайны, лица          | `Scripts\...`, `Splines\...`, `FacesSys\...`, `Faces\...`   |
| конфигурация запуска            | `Config.gm`, `Autoexec.gm`                                   |

Можно заменить любой файл, который читает игра, а в папки, которые игра перечисляет, можно добавлять новые файлы
(например, новые лица или страницы шрифтов): они появляются после собственных файлов игры. Регистр в именах не
важен, `/` и `\` равнозначны. Zip, содержащий одну верхнюю папку с именем самого мода (`BetterSkins.zip` с
`BetterSkins\Sound\...` внутри), читается так, как будто этой папки нет.

## Скрипты

Мод может также содержать скрипты Lua (`*.lua` в корне или в `scripts\`): тексты и картинки HUD, звуки, собственную
страницу настроек на экране Mods. См. [modding/LUA_SCRIPTING.ru.md](modding/LUA_SCRIPTING.ru.md).

## Форматы

Игра запрашивает свои оригинальные имена файлов; мод может дать тот же файл в другом формате под тем же именем с
другим расширением, и exe его преобразует:

- **Текстуры** (игра запрашивает `имя.csi`): `имя.csi`, `имя.png` или `имя.dds`.
  - Папки качества: мод может содержать `Textures.1\x.csi`, `Textures.2\x.csi` и `Textures.3\x.csi` (каждый заменяет
    файл в той же папке; игра читает папки выбранного качества текстур, лучшую первой) и / или `Textures\x.csi`
    (заменяет все три; файл в самой папке качества важнее). Текстура мода используется при любой настройке качества:
    если в моде она есть только в другой папке качества, чем предпочтительная, берётся она, а не файл игры.
  - Картинки языковой папки (`Language\English\logoRC_Main.csi`, логотипы меню и сообщения гонки) заменяются так же,
    под именем папки языка.
  - Собственный `.csi` мода читается снисходительно: любой размер. Если заголовок называет больше mip-уровней, чем
    есть в файле (так пишут некоторые инструменты при увеличении картинки: заголовок оригинала с 8 уровнями, в файле
    только первый), недостающие уровни создаются (файлы ARGB8888) или файл читается с теми уровнями, что есть
    (другие форматы); число mip 0 считается как 1. `.csi`, в котором нет даже первого уровня, отклоняется (с
    записью в журнал).
  - PNG через Windows Imaging Component (встроен в Windows): 8 / 16 бит, палитра, оттенки серого, с альфой или без.
  - DDS: BC1 (DXT1), BC2 (DXT2/3), BC3 (DXT4/5), BC4 (ATI1), BC5 (ATI2), BC7 (заголовок DX10) и несжатые
    RGBA / RGB / BGRA / 565 / 1555 / 4444 / яркость / альфа. Mip-уровни используются как есть в файле; недостающие
    создаются (среднее 2 x 2). BC4 показывается серым, BC5 — красным / зелёным. Форматы sRGB берутся как обычные
    значения.
  - Кубические текстуры (отражение краски машин, `cubemap_racer`): игра читает `cubemap_racer.csi` и шесть его
    граней `cubemap_racer.1.csi` .. `.6.csi` (+X, -X, +Y, -Y, +Z, -Z). Один кубический DDS `cubemap_racer.dds` со
    всеми шестью гранями заменяет все семь файлов. Если заменять их по одному, каждая грань должна быть размера
    `cubemap_racer.csi`.
- **Звуки и музыка** (игра запрашивает звуковые эффекты `.au` / `.wav` и музыку `.mp3`): любой из `.au`, `.wav`,
  `.mp3`, `.ogg` может заменить любой другой.
  - WAV: PCM 8 / 16 / 24 / 32 бит, float 32 / 64 бит, WAVE_FORMAT_EXTENSIBLE, другие кодеки WAV через Media
    Foundation; `.au`: собственный формат игры (RIFF WAVE с именем .au) или Sun / NeXT .au (mu-law, A-law, PCM,
    float); MP3 (и другие форматы, которые декодирует Windows) через Media Foundation; OGG Vorbis через stb_vorbis.
  - Любая длина, частота дискретизации и число каналов. Звуковые эффекты преобразуются в 16-битный PCM (8 / 16-битный
    моно или стерео PCM остаётся точно таким же); больше двух каналов сводятся в стерео; частота вне 100 ..
    200000 Гц пересчитывается в 48000 Гц. Музыка в формате, который DirectShow сам не играет (.ogg, .au), или
    внутри zip записывается во временный .wav / копию в `%TEMP%\RcCarsRe_mods_<id процесса>\`, который удаляется при
    выходе из игры.

## Если файл мода не работает

Если файл мода нельзя открыть, прочитать, распаковать или декодировать (текстура, звук, музыкальный трек, файл
настроек или текста), игра читает вместо него свой оригинальный файл и один раз записывает причину в журнал
(`Mods: <mod>: <file> can't be decoded (...); the game's own file is used`); этот файл больше не предлагается, пока
моды не будут применены заново. Текстура никогда не остаётся отсутствующей из-за мода, а при включённых модах
отсутствующая текстура интерфейса больше не останавливает запуск на экране загрузки (это записывается в журнал, и
меню продолжают работать). Файлы, содержимое которых игра сама проверить не может (повреждённый внутри `.sb` трассы,
скрипт с неверными значениями), по-прежнему читаются так, как их даёт мод.

## Размеры

У игры нет собственных ограничений размера: текстура 4096 x 4096 может заменить текстуру 256 x 256 и используется в
своём размере при любом качестве текстур (`TexQual`, `Textures.1 / .2 / .3`: текстура мода побеждает в каждой папке
качества). Текстуры не обязаны быть квадратными или степенью двойки. Ограничение — у Direct3D 11: 16384 текселя на
сторону. Текстура получает не более 10 mip-уровней (ограничение формата .csi), что доходит до 1 / 512 размера:
для выборки этого более чем достаточно. Память: текстура 4096 x 4096 занимает около 85 МБ во время загрузки и 85 МБ
видеопамяти.

Что сохраняет смысл в пикселях: страницы шрифтов (шрифты Smash в `Language\...` и шрифт приборной панели) режутся на
ячейки букв фиксированного размера в пикселях, поэтому страница шрифта должна сохранять размер и раскладку
оригинала. Некоторые картинки код игры читает попиксельно (карты освещения трасс, портреты гонщиков в `Faces` /
`FacesSys`): для них другие размеры не проверялись; для надёжности сохраняйте оригинальный размер.

## Порядок загрузки

Порядок загрузки — это список, **верх которого — самый важный мод**: если у двух модов есть один и тот же файл (в
любом его формате), используется файл мода, который выше в списке. Внутри одного мода файл с запрошенным расширением
важнее других его форматов.

1. `[Modern] ModOrder=A,B,C` (необязательно): эти моды стоят наверху в этом порядке: `A` важнее `B`, `B` важнее `C`.
   (Изменено 2026-11-15: раньше побеждало более позднее имя.)
2. Моды, которые ModOrder не называет, идут ниже, по имени (без учёта регистра; среди них побеждает первый по
   имени). Папка и zip с одинаковым именем: папка идёт первой.
3. `[Modern] ModsDisabled=A,B` (необязательно): эти моды не загружаются. `A` означает и папку, и zip с именем A,
   `A.zip` — только zip, `A\` — только папку (те же формы работают в ModOrder).
4. Мод с одинаковым именем в обеих папках mods (рядом с exe и в папке игры) берётся один раз — тот, что рядом с exe.

## Экран Mods

При `[Modern] ModsMenu=1` (по умолчанию) вместо пункта главного меню «Demo play» (демо-гонка ещё не пересобрана)
стоит **Mods** (Modok / Моды / Mody на языке игры). Экран показывает все найденные моды, загруженные и нет, в порядке
загрузки (верхний побеждает), с числом их файлов, числом заменяемых файлов игры и красным `!`, если какие-то файлы не
удаётся декодировать (подробности выбранного мода показаны под списком, причины — в `game_dbg.log`). В первой строке
**Mods** включает и выключает всю поддержку модов (`[Modern] Mods`).

- Вверх / вниз (или мышь) выбирают мод, PgUp / PgDn прокручивают страницу; влево / вправо, Enter или пробел (кнопка
  A геймпада) включают или выключают его;
- **Move up** / **Move down** (кнопки меню справа) перемещают выбранный мод по списку;
- **Refresh** заново просматривает обе папки mods: добавленные моды появляются внизу списка, включёнными; удалённые
  исчезают; все счётчики пересчитываются. Ещё не применённые порядок и переключатели сохраняются. Refresh ничего не
  загружает: это работа Apply;
- **Apply** записывает `Mods`, `ModOrder` (все моды, верхний первым) и `ModsDisabled` в `RcCarsRe.ini` (если они
  изменились), показывает «Applying mods...», сразу загружает моды по-новому, сообщает «Mods applied» и возвращается
  в главное меню. Apply без изменений тоже заново загружает файлы модов (используйте после правки файлов мода);
- **Main menu** (или Esc / кнопка B геймпада) отменяет изменения.

Экран пишет только в `RcCarsRe.ini`, никогда в папки mods или папки игры.

### Что Apply перезагружает сразу (без перезапуска)

- все текстуры из папок текстур и языковой папки (меню, логотипы, кнопки, раскраски машин, грани `cubemap_racer`,
  картинки интерфейса), страницы шрифтов Smash и лица гонщиков (`FacesSys`, `Faces`);
- звуковые эффекты (`Sound\*`, в том числе звуки меню) и таблицы `snd.ini` / `chn.ini`;
- музыку: файл каждого трека ищется заново (MP3 / OGG / WAV мода вместо трека), и музыка меню начинается заново;
- файлы ползунков `Settings\*` (перечитываются при следующем использовании; ваши собственные настройки на страницах
  Options хранятся в `RCCars.crs` и остаются как есть);
- языковую таблицу `Language\Game\<язык>.tbl` (тексты главного меню сразу, остальных экранов при открытии);
- `Scripts\championship.ini` и `Scripts\AIlayouts.ini`.

Всё, что относится к гонке (трассы, машины, их `.sb`, пути ИИ, `CarProfiles`, `Profiles`, `UPGRADES.ini`, скрипты
трасс), читается при загрузке гонки, поэтому следующая гонка уже берёт файлы модов.

### Что требует перезапуска

Файлы, которые игра читает только при запуске: `Config.gm`, `Autoexec.gm` (и любые `*.gm`: папки, переменные,
список музыкальных треков), базы сцен `RCCars.sb`, `Interface.sb` и `RaceTextures.sb` (их объекты, машины главного
меню, встроенные картинки, список текстур интерфейса и его звуковые каналы) и `Splines\`. Если мод меняет один из
этих файлов, Apply сообщает об этом («Some files need a restart»), а `game_dbg.log` называет файлы. Картинки,
встроенные в базу данных (`.sb`), по-прежнему берутся из базы, как при запуске. Интро-видео играют только при
запуске. Папка языка (`Language\<имя>\`, из строки 2 таблицы) остаётся той, что была при запуске.

## Что нельзя модифицировать

- Сохранения игроков (`Players\`, все `*.scp`), записи призраков (`GhostRecords\`) и хранилище настроек `RCCars.crs`
  (`RCCars.crs.bak`): их пишет игра, поэтому копия из мода игнорируется (с записью в журнал).
- Файлы вне папки игры (абсолютный путь в `Config.gm`), exe и его DLL, `RcCarsRe.ini`.
- Zip-архивы: только записи «stored» и «deflate», без шифрования, без ZIP64 (архивы больше 4 ГБ / 65535 файлов).
- Встроенные текстуры файлов трасс читаются из самого файла `.sb`: заменяйте весь `.sb` или текстуры, которые
  называют трассы, — они ищутся в папках `Textures.*`, как и все остальные текстуры.

## Журнал

`game_dbg.log` рядом с exe перечисляет при запуске: каждый найденный мод (zip или папка, число файлов), каждый файл и
что он заменяет (`Mods: BetterSkins: Textures\car_askin11.png replaces textures.1\car_askin11.csi`), новые файлы,
файлы, скрытые более поздним модом, проигнорированные файлы и файлы, которые нельзя декодировать (с причиной; для них
используется файл игры), затем сводку. Преобразования записываются, когда игра загружает файл (`decoded (PNG
2048x2048)`, `converted to a ...-byte WAVE`).

В папку `mods` или папки игры никогда ничего не записывается.
