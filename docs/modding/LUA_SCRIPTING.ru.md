# Скрипты Lua в модах

[English](LUA_SCRIPTING.en.md) | [Magyar](LUA_SCRIPTING.hu.md) | **Русский** | [Polski](LUA_SCRIPTING.pl.md)

RcCarsRe умеет запускать небольшие скрипты Lua, входящие в мод. Скрипт может читать состояние гонки (трасса, круги,
машины, позиции, время кругов), реагировать на события (круг, контрольная точка, удар, вода, возврат на трассу,
конец гонки) и делать локальные вещи: выводить тексты, картинки и прямоугольники на HUD, проигрывать звуки, писать в
журнал и хранить свои настройки. Скрипты не могут менять гонку, машины и файлы игры.

Язык — [Lua 5.4](https://www.lua.org/manual/5.4/) (Lua 5.4.9, лицензия MIT, см.
[LUA_LICENSE.txt](LUA_LICENSE.txt)).

## 1. Обзор

- Каждый включённый мод (папка или zip в папке `mods`, см. [MODDING.ru.md](../MODDING.ru.md)) может содержать файлы `.lua`.
- Каждый мод получает своё состояние Lua. Моды не видят глобальные переменные друг друга.
- Моды загружаются в порядке экрана «Моды» снизу вверх: сначала мод с наименьшим приоритетом, последним — верхний.
- Игра вызывает глобальные функции-события скрипта (`onFrame`, `onLap`, ...), если они определены.
- Всё, что делает скрипт, остаётся на вашем компьютере: HUD, звук, журнал, файл настроек. Скрипты никогда ничего не
  отправляют по сети и не влияют на других игроков в сетевой гонке.

## 2. Расположение файлов

```
mods\
  my_mod\                 (или my_mod.zip с тем же содержимым)
    main.lua              входной скрипт (любой *.lua в корне мода)
    scripts\
      hud.lua             входной скрипт (любой *.lua прямо в scripts\)
      lib\util.lua        сам не загружается: загрузите его через rc.include("scripts/lib/util.lua")
    sounds\ding.wav       собственный звук мода для rc.playSound("ding")
    textures\icon.png     собственная картинка мода для rc.hudImage(..., "icon", ...)
```

- Входные скрипты: все `*.lua` в корне мода и прямо в `scripts\`, по порядку имён.
- Файлы из более глубоких папок загружаются только через `rc.include`.
- Скрипты и тексты — в UTF-8. Тексты переводятся в кодовую страницу шрифта игры для текущего языка.

## 3. Включение

В `RcCarsRe.ini` (рядом с `RcCarsRe.exe`), раздел `[Modern]`:

| Ключ | Значения | По умолчанию | Смысл |
|---|---|---|---|
| `Mods` | 0 / 1 | 1 | читаются папки mods (нужно для скриптов) |
| `LuaScripts` | 0 / 1 | 1 | скрипты Lua модов работают |
| `LuaBudget` | 10000 .. 100000000 | 1000000 | сколько инструкций Lua может выполнить один вызов события |

Экран «Моды» (главное меню, «Моды») включает и выключает моды. **Применить** сразу перезагружает все скрипты:
старые состояния закрываются, загружается новый набор модов.

## 4. События

Определите их как глобальные функции. Все необязательны.

| Событие | Когда |
|---|---|
| `onLoad()` | после загрузки входных скриптов мода |
| `onMenu(name)` | сменился верхний экран: `main`, `options`, `quickrace`, `multiplayer`, `twoplayers`, `twosetup`, `players`, `newplayer`, `credits`, `ghost`, `garage`, `championship`, `champwin`, `mods`, `modsettings`, `pause`, `race`, `results`, `none`, `other` |
| `onRaceStart(info)` | на старте (GO); `info` — таблица `rc.race()` |
| `onFrame(dt)` | каждый кадр (и в меню); `dt` — время кадра в секундах |
| `onLap(car, lap, lapTime)` | машина закончила круг номер `lap` за `lapTime` секунд |
| `onCheckpoint(car, index)` | машина прошла контрольную точку `index` (1 — линия старта/финиша) |
| `onHit(car, strength)` | игра засчитала удар: 1 = «Hit!», 2 = «Great hit!» |
| `onWater(car)` | машина попала в воду |
| `onRespawn(car)` | машину вернули на трассу |
| `onRaceEnd(results)` | один раз за гонку, когда запускается финишный скрипт (все игроки финишировали) |
| `onOptionChanged(key, value)` | на странице «Настройки» мода изменили опцию |

`car` — номер машины, 1 .. `rc.race().cars`. `results` — список в порядке мест; у каждого элемента есть `car`,
`place`, `finished`, `time`, `bestLap` (нет, если не было), `lap`, `name`.

## 5. Справочник API (таблица `rc`)

### Чтение

| Функция | Возвращает |
|---|---|
| `rc.version` | версия API (`"1.0"`) |
| `rc.modName` | имя мода |
| `rc.race()` | `{track, trackIndex, laps, time, state, cars, mode, checkpoints}`. `time` — секунды после старта (до него -1). `state` = `menu`, `prestart`, `racing`, `paused`, `finished` (игрок 1 финишировал), `results` |
| `rc.car(i)` | `{index, x, y, z, speed, gear, lap, lapTime, bestLap, place, isPlayer, isAi, isGhost, player, finished, name}` или `nil`. `speed` в км/ч; `player` = 1 / 2 у машины игрока |
| `rc.player(n)` | таблица машины игрока `n` (1 или 2, по умолчанию 1) или `nil` |
| `rc.screen()` | `{w, h, menu, vr, split}`: размер рендера в пикселях, имя текущего экрана, VR включён, разделённый экран |

### HUD (рисуется только в этом кадре: вызывайте каждый кадр из `onFrame`)

Координаты — виртуальный экран 800 x 600, растянутый на всю картинку (при разделённом экране — на оба вида, в VR — на
слой HUD). Цвета в виде `0xAARRGGBB`.

| Функция | Смысл |
|---|---|
| `rc.hudText(x, y, text, color, size, align)` | текст шрифтом игры; `size` 1 = размер текста HUD (следует за масштабом UI и `HudScale`); `align` = `"left"` (по умолчанию), `"center"`, `"right"` (x — левый край, середина или правый край) |
| `rc.hudRect(x, y, w, h, color)` | залитый прямоугольник (цвет по умолчанию `0x80000000`) |
| `rc.hudImage(x, y, w, h, texture, color, u0, v0, u1, v1)` | картинка; `texture` — собственный файл мода (имя как путь, также с `.png` / `.dds` / `.csi` и в `textures\`), иначе текстура игры с этим именем; uv по умолчанию 0, 0, 1, 1 |

Не более 512 элементов HUD за кадр и 64 картинок на мод.

### Звук и журнал

| Функция | Смысл |
|---|---|
| `rc.playSound(name, volume)` | проигрывает один раз: собственный файл мода (имя как путь, также с `.wav` / `.ogg` / `.mp3` / `.au` и в `sounds\` или `sound\`), иначе звук игры с этим именем; `volume` 0 .. 1 (по умолчанию 1, умножается на громкость эффектов игры). Возвращает `true`, если звук играет |
| `rc.log(...)` / `print(...)` | строка в `game_dbg.log` (и в консоли -dev) |
| `rc.warn(...)` / `warn(...)` | строка-предупреждение (жёлтая в консоли -dev) |

### Файлы своего мода

| Функция | Смысл |
|---|---|
| `rc.readFile(path)` | байты файла строкой или `nil, сообщение`. Читается только собственный мод скрипта |
| `rc.include(path)` | один раз выполняет файл `.lua` своего мода и возвращает его результат (последующие вызовы возвращают тот же), как `require` |

### Настройки

Хранятся в `Saves\Mods\<mod>.ini` рядом с `RcCarsRe.exe` (`<mod>.zip.ini` для zip-мода), раздел `[Settings]`.
Больше ничего не записывается.

| Функция | Смысл |
|---|---|
| `rc.setting(key, default)` | сохранённое значение, приведённое к типу `default` (логическое, число, строка); без сохранённого значения — `default` или значение опции по умолчанию |
| `rc.setSetting(key, value)` | сохраняет логическое значение, число или строку (`nil` удаляет); файл записывается сразу, поэтому не вызывайте это каждый кадр |
| `rc.options{ ... }` | объявляет опции страницы «Настройки» мода (ниже) |

Ключи: буквы, цифры, `_`, `.`, `-`, не более 63 символов. Значения: не более 1000 байт, без переводов строк.

### Страница «Настройки»

```lua
rc.options{
  {key = "showLap", type = "bool", label = "Show lap time", default = true},
  {key = "size", type = "slider", min = 0, max = 10, step = 1, default = 5, label = "Size"},
  {key = "mode", type = "enum", values = {"small", "big"}, default = "small", label = "Mode",
   labels = {"Small", "Big"}},
}
```

- `label` (и каждый элемент `labels`) — строка или таблица по языкам: `{en = "...", hu = "...", ru = "...", pl = "..."}`.
- У загруженного мода с опциями на экране «Моды» активна кнопка **Настройки**. Её страница использует собственные
  элементы меню игры (переключатели, ползунки, кнопки); изменения сохраняются сразу и вызывается
  `onOptionChanged(key, value)`.
- `rc.setting(key)` возвращает значение опции; кнопка **По умолчанию** на странице восстанавливает значения по умолчанию.

## 6. Ограничения песочницы

- Доступно: базовые функции Lua, `table`, `string`, `math`, `utf8`, `coroutine`, а также `os.clock`, `os.time`,
  `os.date`.
- Недоступно: `io`, остальная часть `os`, `require`, `dofile`, `loadfile`, `debug`, `package`, `string.dump`.
- `load` принимает только текстовые фрагменты (строку; без двоичных фрагментов).
- `collectgarbage` принимает только `"count"`.
- Память: 64 МБ на мод.
- Время: `LuaBudget` инструкций Lua на вызов события. Долгая работа внутри одного библиотечного вызова (например,
  огромный `string.rep` или сложный шаблон) счётчиком инструкций не учитывается; пишите простые скрипты.
- Скрипты никогда не записывают файлы игры, файлы модов и сохранения игроков; единственный записываемый файл —
  файл настроек мода.

## 7. Обработка ошибок

- Ошибка загрузки, ошибка выполнения или превышение бюджета прерывают только этот вызов. Игра продолжается.
- Каждая ошибка записывается в `game_dbg.log` как `Lua [mod] что: файл:строка: сообщение` (с трассировкой стека).
- После 5 ошибок скрипты мода отключаются («mod scripts disabled after repeated errors»). Исправьте скрипт и нажмите
  «Применить» на экране «Моды» (или сохраните файл в режиме разработчика, см. ниже).
- Если вызов использовал больше 80 % бюджета, выдаётся одно предупреждение.

## 8. Режим разработчика (`RcCarsRe.exe -dev`)

- Ошибки и предупреждения видны в окне консоли: строки ошибок красные, предупреждений — жёлтые (и Lua, и игры);
  ошибки также появляются в красной полосе в игре.
- Команда консоли `lua` выводит список модов со скриптами; `lua <код>` выполняет код в состоянии последнего
  загруженного мода, `lua <mod> <код>` — в состоянии этого мода, и печатает результаты (работает и выражение,
  например `lua rc.race().state`).
- Горячая перезагрузка: файлы `.lua` модов-папок проверяются раз в секунду; если один изменился, скрипты этого мода
  загружаются заново (для zip-модов: «Применить»).

## 9. Примеры

В `docs/modding/examples/` два полных мода. Скопируйте папку в `mods\` рядом с `RcCarsRe.exe`:

- `laptime_hud`: текущее, предыдущее и лучшее время круга игрока 1 в рамке; опции для лучшего круга, размера и угла.
- `checkpoint_sound`: на каждой контрольной точке игрока 1 проигрывает собственный `sounds\ding.wav` мода и
  показывает её номер.

Минимальный скрипт:

```lua
function onLap(car, lap, t)
  local p = rc.player(1)
  if p and p.index == car then rc.log(string.format("lap %d: %.2f s", lap, t)) end
end

function onFrame(dt)
  if rc.race().state == "racing" then
    rc.hudText(400, 20, "Hello from Lua", 0xffffff40, 1, "center")
  end
end
```

## 10. Устранение неполадок

| Проблема | Проверьте |
|---|---|
| Ничего не происходит | `LuaScripts=1` и `Mods=1` в `RcCarsRe.ini`; мод включён на экране «Моды»; файл лежит в корне мода или в `scripts\`; в `game_dbg.log` есть `Lua [mod]: ... loaded` |
| «mod scripts disabled after repeated errors» | прочитайте первые строки ошибок `Lua [mod]` в `game_dbg.log`, исправьте скрипт, нажмите «Применить» |
| «instruction budget exceeded» | событие сделало слишком много работы за раз; распределите её по кадрам или увеличьте `LuaBudget` |
| Элемент HUD не виден | вызовы HUD действуют только один кадр: вызывайте их из `onFrame`; проверьте байт альфы цвета (`0xFF......` — непрозрачный) |
| «texture ... not found» / «sound ... not found» (жёлтые) | имя и папка файла в моде; картинки PNG, DDS или CSI; звуки WAV, OGG, MP3 или AU |
| В тексте `?` | пишите скрипт в UTF-8; шрифт игры содержит только символы кодовой страницы своего языка |
| Ошибки в консоли -dev | строки ошибок красные, предупреждений — жёлтые; те же строки есть в `game_dbg.log` |
