# Скрипты Lua в модах

[English](LUA_SCRIPTING.en.md) | [Magyar](LUA_SCRIPTING.hu.md) | **Русский** | [Polski](LUA_SCRIPTING.pl.md)

RcCarsRe умеет запускать небольшие скрипты Lua, входящие в мод. Скрипт может читать состояние гонки (трасса, круги,
машины, позиции, время кругов), реагировать на события (круг, контрольная точка, удар, прыжок, обгон, пауза, конец
гонки ...) и делать локальные вещи: выводить тексты, картинки и прямоугольники на HUD, проигрывать звуки, двигать
камеру, менять туман, солнце и освещение, включать вибрацию геймпада, писать в журнал и хранить свои настройки и
статистику. Скрипты не могут менять гонку, машины и файлы игры, за одним исключением: скрипт игрового
режима (глава 6, API 1.4) ведёт правила своих гонок (пока только в одиночной игре).

Язык — [Lua 5.4](https://www.lua.org/manual/5.4/) (Lua 5.4.9, лицензия MIT, см.
[LUA_LICENSE.txt](LUA_LICENSE.txt)). Здесь описана версия API **1.5**.

## 1. Обзор

- Каждый включённый мод (папка или zip в папке `mods`, см. [MODDING.ru.md](../MODDING.ru.md)) может содержать файлы `.lua`.
- Каждый мод получает своё состояние Lua. Моды не видят глобальные переменные друг друга.
- Моды загружаются в порядке экрана «Моды» снизу вверх: сначала мод с наименьшим приоритетом, последним — верхний.
- Игра вызывает глобальные функции-события скрипта (`onFrame`, `onLap`, ...), если они определены.
- Всё, что делает скрипт, остаётся на вашем компьютере: HUD, звук, камера, туман, свет, геймпад, журнал, его
  собственные файлы. Скрипты никогда ничего не отправляют по сети и не влияют на других игроков в сетевой гонке.

## 2. Расположение файлов

```
mods\
  my_mod\                 (или my_mod.zip с тем же содержимым)
    main.lua              входной скрипт (любой *.lua в корне мода)
    scripts\
      hud.lua             входной скрипт (любой *.lua прямо в scripts\)
      lib\util.lua        сам не загружается: загрузите его через rc.include("scripts/lib/util.lua")
    sounds\ding.wav       собственный звук мода для rc.playSound("ding")
    textures\icon.png     собственная картинка мода для rc.hudImage(..., "icon", ...)
```

- Входные скрипты: все `*.lua` в корне мода и прямо в `scripts\`, по порядку имён.
- Файлы из более глубоких папок загружаются только через `rc.include`.
- Скрипты и тексты — в UTF-8. Тексты переводятся в кодовую страницу шрифта игры для текущего языка.

## 3. Включение

В `RcCarsRe.ini` (рядом с `RcCarsRe.exe`), раздел `[Modern]`:

| Ключ | Значения | По умолчанию | Смысл |
|---|---|---|---|
| `Mods` | 0 / 1 | 1 | читаются папки mods (нужно для скриптов) |
| `LuaScripts` | 0 / 1 | 1 | скрипты Lua модов работают |
| `LuaBudget` | 10000 .. 100000000 | 1000000 | сколько инструкций Lua может выполнить один вызов события |

Экран «Моды» (главное меню, «Моды») включает и выключает моды. **Применить** сразу перезагружает все скрипты:
старые состояния закрываются, загружается новый набор модов.

Функции геймпада также следуют вашим собственным настройкам в том же разделе: `Rumble` (0 = без вибрации),
`LightBar` (`off` = световая панель никогда не меняется) и `AdaptiveTriggers` (0 = без эффектов курков). Скрипт не
может включить то, что вы выключили.

## 4. События

Определите их как глобальные функции. Все необязательны.

| Событие | Когда |
|---|---|
| `onLoad()` | после загрузки входных скриптов мода |
| `onMenu(name)` | сменился верхний экран: `main`, `options`, `quickrace`, `multiplayer`, `twoplayers`, `twosetup`, `players`, `newplayer`, `credits`, `ghost`, `garage`, `championship`, `champwin`, `mods`, `modsettings`, `pause`, `race`, `results`, `none`, `other` |
| `onRaceStart(info)` | на старте (GO); `info` — таблица `rc.race()` |
| `onFrame(dt)` | каждый кадр (и в меню); `dt` — время кадра в секундах |
| `onLap(car, lap, lapTime)` | машина прошла круг номер `lap` за `lapTime` секунд |
| `onCheckpoint(car, index)` | машина прошла контрольную точку `index` (1 — линия старта/финиша) |
| `onHit(car, strength)` | игра засчитала удар: 1 — «Hit!», 2 — «Great hit!» |
| `onWater(car)` | машина попала в воду |
| `onRespawn(car)` | машину вернули на трассу |
| `onRaceEnd(results)` | один раз за гонку, когда запускается финишный скрипт (все игроки финишировали) |
| `onOptionChanged(key, value)` | на странице настроек мода изменили параметр |
| `onBoost(car, on)` | (1.1) ускоритель машины включился (`true`) или выключился (`false`) |
| `onJump(car)` | (1.1) машина в гонке уже 0,25 с в воздухе (мелкие кочки не считаются) |
| `onLand(car, airTime)` | (1.1) эта машина снова на земле; `airTime` — секунды в воздухе |
| `onOvertake(car, otherCar, newPlace)` | (1.1) `car` занял место `newPlace`, обогнав `otherCar` (проверяется раз в кадр во время гонки) |
| `onCollision(car1, car2, strength, kind)` | (1.1) контакт: `kind` = `"car"` (два гонщика; `strength` — скорость сближения в км/ч) или `"roadcar"` (гонщик и дорожная машина; `car2` = `nil`, `strength` — скорость гонщика в км/ч). Один вызов на пару, пока контакт продолжается (снова после 0,5 с без контакта) |
| `onDogAttack(car)` | (1.1) собака начинает атаку на `car`: останавливается и лает на неё (собаки в игре не кусают; наезд на собаку — «Great hit!», см. `onHit`) |
| `onPause(kind)` | (1.1) гонка на паузе: `kind` = `"menu"` (меню паузы) или `"quick"` (быстрая пауза) |
| `onResume()` | (1.1) гонка продолжается после паузы |
| `onChat(name, text)` | (1.1) пришла строка сетевого чата (и ваши собственные); `name` — отправитель, `""` для строк сервера и игры. Только чтение |
| `onCountdown(n)` | (1.1) обратный отсчёт гонки, в тот же момент, что и цифры и сигналы: `n` = 3, 2, 1 и 0 на GO |

`car` — номер машины, 1 .. `rc.race().cars`. `results` — список в порядке мест; у каждого элемента есть `car`,
`place`, `finished`, `time`, `bestLap` (отсутствует, если его нет), `lap`, `name`.

## 5. Справочник API (таблица `rc`)

### Чтение

| Функция | Возвращает |
|---|---|
| `rc.version` | строка версии API (`"1.5"`) |
| `rc.modName` | имя мода |
| `rc.race()` | `{track, trackIndex, laps, time, state, cars, mode, checkpoints}`. `time` — таймер гонки HUD в секундах (-1 до старта). `state` = `menu`, `prestart`, `racing`, `paused`, `finished` (игрок 1 финишировал), `results` |
| `rc.car(i)` | `{index, x, y, z, speed, gear, lap, lapTime, bestLap, raceTime, place, isPlayer, isAi, isGhost, player, finished, name}` или `nil`. `speed` в км/ч; `player` = 1 / 2 у машины игрока; `raceTime` — время машины с момента старта (останавливается на финише) |
| `rc.player(n)` | таблица машины игрока `n` (1 или 2, по умолчанию 1) или `nil` |
| `rc.screen()` | `{w, h, menu, vr, split}`: размер изображения в пикселях, имя текущего экрана, включён ли VR, разделённый экран |
| `rc.formatTime(seconds, format)` | (1.1) время так, как его пишет игра: `"m:ss.hh"`, как таймер HUD (`0:15.89`), или при `format = "short"` — `"m:ss"` |

Время кругов работает как в игре: `lap` равен 0, пока машина впервые не пересечёт линию старта/финиша, и каждое
время круга (и первого тоже) отсчитывается от пересечения этой линии. Поэтому на первом круге `lapTime` меньше
`rc.race().time` на время, за которое машина доехала от своего места на старте до линии. Надпись круга, таблица
результатов игры и `onLap` используют те же значения.

### HUD (рисуется только в этом кадре: вызывайте каждый кадр из `onFrame`)

Координаты — виртуальный экран 800 x 600, растянутый на всё изображение (при разделённом экране — на оба вида,
в VR — на слой HUD). Цвета в формате `0xAARRGGBB`.

| Функция | Смысл |
|---|---|
| `rc.hudText(x, y, text, color, size, align)` | текст шрифтом игры; `size` 1 — размер текста HUD (следует масштабу интерфейса и `HudScale`); `align` = `"left"` (по умолчанию), `"center"`, `"right"` (x — левый край, центр или правый край) |
| `rc.hudRect(x, y, w, h, color)` | залитый прямоугольник (цвет по умолчанию `0x80000000`) |
| `rc.hudImage(x, y, w, h, texture, color, u0, v0, u1, v1)` | картинка; `texture` — собственный файл мода (имя как путь, также с `.png` / `.dds` / `.csi` и в `textures\`), иначе текстура игры с таким именем; uv по умолчанию 0, 0, 1, 1 |

Не более 512 элементов HUD за кадр и 64 картинок на мод.

### Звук и журнал

| Функция | Смысл |
|---|---|
| `rc.playSound(name, volume)` | проигрывает один раз: собственный файл мода (имя как путь, также с `.wav` / `.ogg` / `.mp3` / `.au` и в `sounds\` или `sound\`), иначе звук игры с таким именем; `volume` 0 .. 1 (по умолчанию 1, умножается на громкость эффектов игры). Возвращает `true`, если звук играет |
| `rc.log(...)` / `print(...)` | строка в `game_dbg.log` (и в консоль -dev) |
| `rc.warn(...)` / `warn(...)` | строка-предупреждение (жёлтая в консоли -dev) |

### Камера (1.1)

| Функция | Смысл |
|---|---|
| `rc.camera{pos =, offset =, target =, car =, fov =, blend =}` | камера гонки игрока 1 заменяется до вызова `rc.camera(nil)`. `pos = {x, y, z}` — положение камеры в мире; или `offset = {x, y, z}` вместе с `car` — положение относительно этой машины в её собственных осях (x вправо, y вверх, z вперёд); без обоих остаётся положение камеры игры. `target = {x, y, z}` или `car = i` — куда она смотрит (без обоих остаётся направление игры). `fov` — вертикальный угол обзора в градусах, 10 .. 150 (у одиночного вида игры около 64). `blend` — за сколько секунд плавно перейти от камеры игры (0 — сразу) |
| `rc.camera(nil)` | обратно к камере игры (плавно, за то же время `blend`) |
| `rc.cameraInfo()` | текущая камера гонки игрока 1: `{pos = {x, y, z}, dir = {x, y, z}, fov, override, blend}`, вне гонки `nil`. У `pos` / `dir` есть и поля `.x .y .z`; `override` — включена камера скрипта, `blend` 0 .. 1 |

Замена камеры действует только в гонке и только на вид игрока 1: при разделённом экране вид игрока 2 сохраняет
камеру игры, а в VR камерой управляет шлем, поэтому там замена игнорируется (одно предупреждение в журнале).
Камеры меню никогда не меняются. Выход из гонки и перезагрузка модов выключают замену.

### Погода и настроение (1.1)

Они меняют только то, что рисует ваш компьютер. Каждое выключается своей функцией сброса, передачей `nil`,
автоматически в конце гонки (прямо перед `onRaceEnd`, так что скрипт может задать там новое настроение), при выходе
из гонки и при перезагрузке модов. Если несколько модов задают один и тот же эффект, побеждает последний вызов.

| Функция | Смысл |
|---|---|
| `rc.fog{color =, near =, far =, density =}` | туман трассы: `color` = `0xRRGGBB`; `density` на метр 0 .. 1 (туман игры экспоненциальный, трассы используют 0,006 .. 0,026); `near` / `far` в метрах: с ними и без `density` туман линейный от `near` до `far`. Отсутствующие поля сохраняют значения трассы. Туман виден, только если туман игры включён (настройки видео) |
| `rc.resetFog()` | снова туман трассы (как `rc.fog(nil)`) |
| `rc.sun{dir = {x, y, z}}` или `rc.sun{elevation =, azimuth =}` | направление солнца (к солнцу; углы в градусах, азимут поворачивает от +z к +x): тени в реальном времени (`Shadows=realtime`) и освещение машин |
| `rc.resetSun()` | снова солнце трассы |
| `rc.lights{intensity =, color =}` | фонари трасс (только при `PointLights=1`): `intensity` — множитель их силы 0 .. 8, `color` = `0xRRGGBB` вместо их собственного цвета. Возвращает `true`, если точечные источники включены |
| `rc.resetLights()` | снова собственный свет фонарей |
| `rc.water{color =, alpha =}` | море: `color` = оттенок `0xRRGGBB`, `alpha` — множитель прозрачности 0 .. 1 (при `WaterFx=1` оттенок окрашивает и мелководье) |
| `rc.resetWater()` | снова собственный вид моря |

### Отклик геймпада (1.1)

`player` — 1 или 2 (по умолчанию 1). Функции возвращают `true`, если геймпад сейчас может показать эффект.

| Функция | Смысл |
|---|---|
| `rc.rumble(strength, seconds, player)` | импульс вибрации: `strength` 0 .. 1 (умножается на вашу настройку `Rumble`), не более 3 секунд. Ощущается, только пока машина игрока едет в гонке, как собственная вибрация игры |
| `rc.lightBar(r, g, b, player)` | световая панель DualSense / DualShock 4 этого цвета (каждый 0 .. 255) до `rc.lightBar(nil, player)`. Важнее цвета игры; при `LightBar=off` ничего не меняется |
| `rc.triggers{right =, left =, player =}` | адаптивные курки DualSense, пока машина игрока едет в гонке: каждый курок `"off"` или `{mode = "resistance", start = 0 .. 1, force = 0 .. 1}` (постоянное сопротивление начиная с доли хода `start`). До `rc.triggers(nil, player)`; при `AdaptiveTriggers=0` не действует |
| `rc.padHaptics(name, player, volume)` | звук (собственный файл мода или звук игры) на вибромоторах-катушках DualSense, по Bluetooth и USB: нужны `PadHaptics=1` и `Rumble` больше 0; не действует, когда игра в фоне или гонка на паузе. `volume` 0 .. 1, умножается на `PadHapticsVolume`. У DualShock 4 катушек нет |

Перезагрузка модов отменяет световую панель и эффекты курков скрипта.

### Файлы своего мода

| Функция | Смысл |
|---|---|
| `rc.readFile(path)` | байты файла строкой или `nil, сообщение`. Читается только собственный мод скрипта |
| `rc.readUserFile(suffix)` | (1.2) собственный файл игрока `Saves\Mods\<mod>.<suffix>` рядом с `RcCarsRe.exe` (например `"controls.ini"`: настройки, переживающие обновления мода) или `nil, сообщение`. Только эта папка и имя самого мода; `suffix`: буквы, цифры, `_ . -` |
| `rc.include(path)` | один раз выполняет файл `.lua` своего мода и возвращает его результат (последующие вызовы возвращают тот же результат), как `require` |

### Настройки

Хранятся в `Saves\Mods\<mod>.ini` рядом с `RcCarsRe.exe` (`<mod>.zip.ini` для zip-мода), раздел `[Settings]`.

| Функция | Смысл |
|---|---|
| `rc.setting(key, default)` | сохранённое значение, приведённое к типу `default` (логическое, число, строка); без сохранённого значения — `default` или значение параметра по умолчанию |
| `rc.setSetting(key, value)` | сохраняет логическое значение, число или строку (`nil` удаляет); пишет файл сразу, поэтому не вызывайте каждый кадр |
| `rc.options{ ... }` | объявляет параметры страницы настроек мода (ниже) |

Ключи: буквы, цифры, `_`, `.`, `-`, не более 63 символов. Значения: не более 1000 байт, без переводов строк.

### Статистика (1.1)

Хранится отдельно для каждого мода в `Saves\Mods\<mod>.stats.ini` рядом с `RcCarsRe.exe` (`<mod>.zip.stats.ini`
для zip-мода), отдельно от настроек и никогда не в сохранении игрока. Значения — числа или строки (не более
1000 байт), не более 1000 ключей на мод, ключи как у настроек. Изменения хранятся в памяти и записываются разом в
конце гонки, при выходе из гонки, при перезагрузке модов и при выходе из игры, так что функции можно вызывать
сколько угодно часто.

| Функция | Смысл |
|---|---|
| `rc.stats.get(key, default)` | сохранённое значение, или `default` (или `nil`) |
| `rc.stats.set(key, value)` | сохраняет число или строку; `nil` удаляет ключ |
| `rc.stats.add(key, n)` | прибавляет `n` (по умолчанию 1) к числу (отсутствующий ключ считается 0) и возвращает новое значение |

### Страница настроек

```lua
rc.options{
  {key = "showLap", type = "bool", label = "Show lap time", default = true},
  {key = "size", type = "slider", min = 0, max = 10, step = 1, default = 5, label = "Size"},
  {key = "mode", type = "enum", values = {"small", "big"}, default = "small", label = "Mode",
   labels = {"Small", "Big"}},
}
```

- `label` (и каждый элемент `labels`) — строка или таблица по языкам: `{en = "...", hu = "...", ru = "...", pl = "..."}`.
- У загруженного мода с параметрами на экране «Моды» активна кнопка **Настройки**. Её страница использует
  собственные элементы меню игры (переключатели, ползунки, кнопки); изменения сохраняются сразу, и вызывается
  `onOptionChanged(key, value)`.
- `rc.setting(key)` возвращает значение параметра; **Значения по умолчанию** на странице восстанавливают их.

### Ввод, пауза, HUD и снимки экрана (1.2)

Это строительные блоки фоторежима, камеры повтора и похожих инструментов. Все они действуют только на вашем
компьютере.

| Функция | Смысл |
|---|---|
| `rc.input.key(name)` | `true`, пока клавиша нажата. Имена: буквы `"A"` .. `"Z"`, цифры, `"F1"` .. `"F24"`, `"Space"`, `"Enter"`, `"Esc"`, `"Tab"`, `"Backspace"`, `"Shift"`, `"Ctrl"`, `"Alt"`, `"Up"`, `"Down"`, `"Left"`, `"Right"`, `"PageUp"`, `"PageDown"`, `"Home"`, `"End"`, `"Insert"`, `"Delete"`, `"Plus"`, `"Minus"`, `"Comma"`, `"Period"`, `"MouseLeft"`, `"MouseRight"`, `"MouseMiddle"` |
| `rc.input.pressed(name)` | `true` в кадре, когда клавишу нажали |
| `rc.input.mouse()` | `{dx, dy, wheel, left, right, middle}`: движение мыши и щелчки колеса в этом кадре, её кнопки |
| `rc.input.pad(player)` | `{lx, ly, rx, ry, lt, rt, kind, buttons = {..}, pressed = {..}}` или `nil` без геймпада. Стики -1 .. 1 (вверх положительно), курки 0 .. 1, `kind` = `"xinput"`, `"ds4"`, `"dualsense"`. Имена кнопок (каждая есть и в `pressed`, true в кадре нажатия): `a` / `cross`, `b` / `circle`, `x` / `square`, `y` / `triangle`, `lb` / `l1`, `rb` / `r1`, `back` / `view` / `share` / `create` / `select`, `start` / `menu` / `options`, `ls` / `l3`, `rs` / `r3`, `guide` / `ps`, `touchpad`, `mute`; в `buttons` есть и крестовина: `up`, `down`, `left`, `right` |
| `rc.input.capture(on)` | пока включено, управление машиной и Esc / Start меню паузы не получают клавиши и кнопки: их использует скрипт (например, стики для свободной камеры) |
| `rc.pause(on)` | останавливает гонку, как меню паузы (часы гонки, физика, ИИ, вода, частицы, анимации, звуки), без меню. В сетевой гонке возвращает `false` |
| `rc.timeScale(s)` | замедление, `s` 0,05 .. 1 (1 = обычная скорость). В сетевой гонке `false`. Для полной остановки — `rc.pause` |
| `rc.hud(show)` | `false` скрывает собственный HUD игры (кокпит, приборы, стрелку, карту, список гонщиков, сообщения, строки чата, ShowFps); `rc.hudText` / `rc.hudImage` / `rc.hudRect` скрипта по-прежнему рисуются |
| `rc.screenshot{hideScriptHud =, scale =}` | сохраняет следующий кадр в PNG в папку `Screenshots` рядом с `RcCarsRe.exe` и возвращает имя файла. `hideScriptHud` (по умолчанию `true`) убирает из этого кадра элементы HUD скрипта. Делается только `scale = 1` (кадр как на экране) |
| `rc.graphics{shadows =, reflections =}` | (1.3) переключает `Shadows` / `Reflections` на этот сеанс: каждое `"original"`, `"realtime"` или `"off"` (отсутствующие поля не меняются). `rc.graphics()` возвращает текущие `{shadows, reflections}`. Ini не записывается: игра возвращает свои значения в конце гонки, при выходе из гонки, при перезагрузке модов и при ошибке скрипта. Первое включение realtime создаёт карты теней / кубы отражений (короткая заминка, несколько сотен МБ видеопамяти); при следующих переключениях они используются снова. Разрешено в сетевых гонках (меняется только ваша картинка) |

- `rc.camera{...}` принимает и `roll = градусы` (положительно — по часовой стрелке) и работает, пока гонка на паузе.
- Ввод читается, только когда окно игры на переднем плане и никто не печатает в текстовое поле (поле меню,
  строка сетевого чата). Работает и только с клавиатурой, и только с геймпадом.
- Недоступно (в рендерере нет дешёвого способа): глубина резкости, снимки `scale = 2`, экспозиция / насыщенность.
  Для настроения — `rc.fog`, `rc.sun`, `rc.lights` и `rc.water`.
- Безопасность: паузу, скрытый HUD, захват ввода, замедление и камеру игра снимает в конце гонки, при выходе из
  гонки, при перезагрузке модов и когда скрипт падает с ошибками или выключается, так что сломанный скрипт никогда
  не оставит игру остановленной или без HUD.

### Как построить фоторежим

Пример-мод `photo_mode` (в `docs/modding/examples/`) — полный фоторежим в одном скрипте. Его основа:

```lua
local on, pos, yaw, pitch = false, nil, 0, 0

local function enter()
  local c = rc.cameraInfo()
  if not c or not rc.pause(true) then return end      -- нет камеры гонки или сетевая гонка
  rc.hud(false)
  rc.input.capture(true)
  pos = {c.pos.x, c.pos.y, c.pos.z}
  yaw, pitch = math.atan(c.dir.x, c.dir.z), math.asin(c.dir.y)
  on = true
end

local function leave()
  rc.camera(nil); rc.hud(true); rc.input.capture(false); rc.pause(false)
  on = false
end

function onFrame(dt)
  if rc.input.pressed("P") then if on then leave() else enter() end return end
  if not on then return end
  if rc.input.pressed("Esc") then leave() return end
  local m = rc.input.mouse()
  yaw, pitch = yaw + m.dx * 0.003, math.max(-1.5, math.min(1.5, pitch - m.dy * 0.003))
  local fx, fy, fz = math.sin(yaw) * math.cos(pitch), math.sin(pitch), math.cos(yaw) * math.cos(pitch)
  local go = (rc.input.key("W") and 1 or 0) - (rc.input.key("S") and 1 or 0)
  pos = {pos[1] + fx * go * 6 * dt, pos[2] + fy * go * 6 * dt, pos[3] + fz * go * 6 * dt}
  rc.camera{pos = pos, target = {pos[1] + fx, pos[2] + fy, pos[3] + fz}}
  if rc.input.pressed("F12") then rc.screenshot{hideScriptHud = true}; rc.stats.add("photos") end
  rc.hudText(400, 580, "F12 photo, P leave", 0xffffffff, 0.7, "center")
end
```

Полный пример летает свободно: W / S вдоль взгляда (и вверх-вниз), A / D вбок (горизонтально, крен его не
поворачивает), Shift / Ctrl прямо вверх / вниз, Q / E крен, Space быстрее, мышь — обзор, колесо — зум, F12 — снимок,
P / Esc — выход; на геймпаде стики, курки (вниз / вверх), бамперы (крен), крестовина (зум), A (снимок) и Back / View
/ Share / Create (вкл / выкл). Без ввода камера стоит: стики и курки проходят через мёртвые зоны (0,2 / 0,1),
инерции нет.

Раскладка лежит в простом текстовом файле мода `photo_mode\controls.ini`, по одному `действие=клавиша` в строке с
комментарием (разделы `[Keyboard]` и `[Pad]`, мёртвые зоны — `deadzone=` / `triggerDeadzone=`). Скрипт читает его
через `rc.readFile` при загрузке (значит, и при «Применить», и при горячей перезагрузке -dev: изменённый `.ini` /
`.txt` мода-папки перезагружает его скрипты) и при каждом включении фоторежима; неизвестное имя даёт жёлтое
предупреждение, и для этого действия остаётся значение по умолчанию. Имена клавиш: `A` .. `Z`, `0` .. `9`, `F1` ..
`F12`, `Ctrl`, `Shift`, `Alt`, `Space`, `Tab`, `Enter`, `Esc`, `Up`, `Down`, `Left`, `Right`, `MouseLeft`,
`MouseRight`, `MouseMiddle`, `WheelUp`, `WheelDown`, `None`; имена кнопок геймпада — как в `rc.input.pad`.
Собственная копия игрока в `Saves\Mods\photo_mode.controls.ini` рядом с `RcCarsRe.exe` (читается через
`rc.readUserFile("controls.ini")`) важнее и переживает обновления мода.

В фоторежиме R (на геймпаде Y / Triangle) включает и выключает тени и отражения в реальном времени (`realtimeGfx=` в controls.ini); при выходе возвращаются значения ini.

## 6. Игровые режимы (1.4)

Мод может добавить **игровой режим**: свои правила на обычной трассе, игрок против машин ИИ. Мод, который вызывает
`rc.registerMode` в своём `onLoad`, появляется в строке **Режим** экрана «Быстрая гонка» (страница сводки гонки, под
мастерством соперников): *Гонка* (обычная гонка) и каждый зарегистрированный режим под своим именем на языке игры.
Гонка режима загружает выбранную трассу как обычно; число соперников ИИ зависит от мастерства (лёгкое 3, нормальное
4, сложное 5), не больше `maxCars` режима.

### Тексты на четырёх языках

Любой текст API может быть строкой или языковой таблицей `{en = "...", hu = "...", ru = "...", pl = "..."}`. Выбирает
текущий язык игры (тот же, что в меню, `[Modern] Language`); если для него нет текста или язык другой, берётся
английский, а без него — первый имеющийся.

| Функция | Значение |
|---|---|
| `rc.lang()` | язык игры: `"en"`, `"hu"`, `"ru"`, `"pl"` или имя папки языка строчными буквами |
| `rc.text(t)` | текст языковой таблицы `t` на текущем языке (строка возвращается как есть) |

### Регистрация режима

```lua
rc.registerMode{
  id = "zombies",                                   -- буквы, цифры, _ . - (уникальный)
  name = {en = "Zombies", hu = "Zombik", ru = "Зомби", pl = "Zombie"},
  description = {en = "...", hu = "...", ru = "...", pl = "..."},
  minCars = 2, maxCars = 6,                          -- 1 .. 6
  checkpoints = false,                               -- нет контрольных точек, стрелки GPS, кругов и финиша
  laps = false,                                      -- нет счётчика кругов (по умолчанию: как checkpoints)
  ai = "script",                                     -- "script": машины ИИ слушают rc.ai; "race": они гоняются
  respawn = false,                                   -- игра не возвращает машины (по умолчанию true)
  hud = {racerList = false, place = false, lap = false, wrongWay = false},   -- части HUD, которые режим скрывает
}
```

При `checkpoints = false` в гонке нет контрольных точек, стрелки GPS, знака «не туда», подсчёта кругов и финиша;
картинка места скрыта. Игре принадлежит только старт (3, 2, 1, GO); после GO гонку ведёт скрипт режима и завершает её
вызовом `rc.mode.finish`. Машина, упавшая в воду или с трассы, возвращается на ближайшую точку линий езды ИИ (при
`respawn = false` вместо этого решает режим).

### События режима (только своему моду режима)

| Событие | Когда |
|---|---|
| `onModeLoad(info)` | гонка режима появилась (с первого кадра, до отсчёта старта), и снова при *Ещё раз*. Здесь задавайте облик режима (туман, звуковой фон) |
| `onModeStart(info)` | на GO. `info` = таблица `rc.race()` плюс `id`, `player` (машина игрока), `minCars`, `maxCars` |
| `onModeFrame(dt)` | каждый кадр, пока идёт гонка (не в паузе и не после финиша) |
| `onModeTimer()` | таймер `rc.mode.timer` дошёл до 0 |
| `onModeEnd()` | один раз после `rc.mode.finish` |
| `onRespawnBlocked(car, reason)` | при `respawn = false`: игра вернула бы машину. `reason` = `"water"` (2 с под водой), `"bounds"` (за пределами уровня), `"zone"` (зона падения), `"key"` (кнопка Reset игрока), `"flip"` (машину на крыше не удалось поставить на колёса), `"stuck"` (физика сочла её застрявшей), `"timed"`, `"aiemu"`. Не чаще раза в секунду на машину |

Обычные события (`onRaceStart`, `onCollision`, `onFrame`, ...) по-прежнему приходят всем модам.

### Управление режимом (вызывать может только скрипт работающего режима)

| Функция | Значение |
|---|---|
| `rc.mode.countdown(seconds, text)` | большой отсчёт в центре экрана (цифры приборной панели), затем `text` на 1,5 с |
| `rc.mode.message(text, seconds, color)` | сообщение под центром экрана (по умолчанию 3 с, белое; `0xRRGGBB`) |
| `rc.mode.timer(seconds)` | верхние часы HUD показывают оставшееся время (последние 10 с красным); `nil` / 0 выключает |
| `rc.mode.timeLeft()` | оставшиеся секунды, `nil` без таймера |
| `rc.mode.clock()` | секунды с начала режима (GO) без пауз |
| `rc.mode.active()` | id работающего режима, `nil` в обычной гонке (может вызвать любой мод) |
| `rc.mode.freeze(car, on)` | удерживает машину (без газа, на тормозе), например для форы |
| `rc.mode.listText(car, text, color)` | список гонщиков HUD показывает этот текст вместо отставания (`nil`: снова отставание) |
| `rc.mode.finish(results, title)` | завершает гонку: все машины финишируют, затем финиш игры и её страница результатов с этими строками. `results` = `{{car =, place =, text =}, ...}`; `title` (по умолчанию имя режима) — заголовок текстового столбца |
| `rc.mode.holdEnd{seconds =, skippable =}` | после `rc.mode.finish`: страница результатов игры появится через `seconds` (по умолчанию 20, не больше 60) секунд — для финальной сцены. `skippable = false` (по умолчанию): кнопки игрока в это время ничего не делают, меню паузы не открывается (закрытие окна по-прежнему выходит из игры). Ошибка скрипта или перезагрузка сразу снимают удержание |
| `rc.mode.showResults()` | удержанная страница результатов сейчас |
| `rc.mode.respawn(on)` | возврат машин игрой вкл. / выкл. для этой гонки (начальное значение — `respawn` из `registerMode`). Выключено: машина на боку или крыше через 2 с ставится на колёса на месте (и машина игрока тоже), но никуда не переносится |
| `rc.mode.respawnCar(car)` | режим возвращает машину на ближайшую точку линий езды ИИ (работает и при `respawn = false`) |
| `rc.setCarTeam(car, n)` | команда машины (любое число; `rc.car(i).team`) |
| `rc.setCar(car, {model =, paint =, physics =})` | машина превращается в другую RC-машину игры: `model` = `"Overkill"`, `"Buggy"` или `"Warhammer"`, `paint` = 1 .. 4 (окраски гаража), `physics` = `true` (по умолчанию: и ездит с физикой этой машины) или `false` (только внешний вид). `rc.setCar(car, nil)`: снова своя машина. Машина сохраняет свои улучшения, звуки и движение |
| `rc.carName(car)` | имя гонщика |
| `rc.distance(car1, car2)` | расстояние между двумя машинами в метрах |

В `rc.car(i)` есть ещё (1.4) `team`, `model` (`""` — своя), `paint` (0 — своя), `frozen` и `contacts`: машины, которых
она коснулась в этом кадре (`{2, 4}`).

### Приказы ИИ (`ai = "script"`)

`rc.ai(car, order)` ведёт машину ИИ (машину игрока никогда; тогда возвращает `false`). ИИ ездит по графу дорог,
построенному из линий езды ИИ трассы (точки у воды и обрывов отмечены: там он сбавляет ход и держится дальше от этой
стороны), ищет кратчайшие пути, при застревании объезжает препятствие и, если режим разрешает возврат, возвращает
машину, застрявшую снова и снова.

| Приказ | Значение |
|---|---|
| `{mode = "chase", target = car}` | едет в эту машину: пока далеко — по дороге, ближе 8 м — прямо на неё (чуть впереди по её скорости) |
| `{mode = "chase", targets = {cars}}` | то же для ближайшей по дороге из этих машин; цель меняет, только если другая явно ближе (по умолчанию: все машины другой команды) |
| `{mode = "flee", from = {cars}, caution = m}` | уезжает от этих машин (по умолчанию: все машины другой команды): к месту в пределах 30 м по дороге, самому далёкому от них (ближайшая важнее всех), путь к которому держится в `caution` метрах (по умолчанию 6) от них; если зажата — по пути с наибольшим простором, мимо преследователя; объезжает преследователя прямо впереди |
| `{mode = "stop"}` | стоит на тормозе |
| `{mode = "path"}` | снова обычная гоночная линия |

Каждый приказ принимает `speed` = 0,1 .. 1, газ (по умолчанию 1). Застрявшая машина (около 2 с без продвижения)
прощупывает путь впереди слева и справа (стены уровня, вода и обрывы считаются препятствием), отъезжает назад,
отворачивая нос от препятствия, объезжает его по свободной стороне через промежуточную точку и продолжает; 4 с она
держится этой стороны, чтобы не пробовать ту же линию. При разрешённом возврате машина, застрявшая трижды за 12 с,
возвращается.

### Звуки и звуковой фон уровня (1.4)

| Функция | Значение |
|---|---|
| `rc.playSound(name, {volume =, loop =, car =, pos =, minDist =, maxDist =, pan =, panTo =})` | звук с дескриптором (`false`, если не играет). `loop = true`: до `rc.stopSound`. `car = i` / `pos = {x, y, z}`: в мире, через DirectSound 3D, как собственные звуки игры: полная громкость в пределах `minDist` (5) метров от камеры, дальше тише, после `maxDist` (60) тише не становится, звучит со своей стороны (звук машины следует за ней; на разделённом экране без направления). `pan` = -1 .. 1 или `panTo = {x, y, z}`: с этой стороны, как видит камера. Не больше 16 на мод одновременно; все стихают при выходе из гонки |
| `rc.stopSound(handle)` | останавливает его |
| `rc.soundPlaying(handle)` | `true`, пока играет |
| `rc.listModFiles(folder, pattern)` | собственные файлы мода в этой папке с подходящими именами (`*`, `?`), напр. `rc.listModFiles("sounds", "hit*.wav")`; пустые файлы пропускаются (с предупреждением) |
| `rc.levelAmbient(on, music)` | `false` глушит зацикленный звуковой фон уровня (фоновые петли, море, ручьи и водопады; разовые звуки — удар о предмет или камень, голоса — остаются, как и звуки машин, эффектов и скриптов); `music` = дБ музыки гонки (0 как настроено, -100 тишина; музыка меню не меняется). Восстанавливается при выходе из гонки, перезагрузке и остановке скриптов мода |
| `rc.fog{...}` | (1.4) возвращает `true`, если туман игры виден (Настройки / Видео: туман вкл.) |
| `rc.hudParts{racerList =, place =, lap =, gps =, map =, timer =, speedo =, boost =, wrongWay =}` | `false` скрывает эту часть HUD игры (список гонщиков, место, круг, стрелку GPS, мини-карту, таймер, спидометр, ускоритель, знак «не туда» и его звук), `true` снова показывает; без аргумента — таблица того, что видно. Восстанавливается при выходе из гонки, *Ещё раз*, перезагрузке и остановке скриптов |
| `rc.textWidth(text, size)` | ширина текста `rc.hudText` в единицах 800 x 600 при этом размере (с масштабом интерфейса и HudScale), чтобы центрировать или выравнивать тексты; `rc.hudText` также принимает последним аргументом `{align = "center"}` (или `"right"`) |
| `rc.replaceTexture(gameTexture, modFile)` | текстура игры с этим именем (уже загруженная, напр. кожа пешехода или чайки) показывает картинку мода (`.png` / `.dds` / `.csi`, также в `textures\` или `skins\`) до `rc.restoreTexture(name)` / `rc.restoreTextures()`; сохраняется при перезагрузке текстур; возвращается сама при выходе из гонки, *Ещё раз*, перезагрузке и остановке скриптов. В отличие от файла в папке `Textures\` мода действует, только пока этого хочет скрипт |

### Пути камеры (1.4)

| Функция | Значение |
|---|---|
| `rc.cameraPath{points = {{pos =, target =, fov =, roll =}, ...}, duration =, ease =, blend =}` | гоночная камера игрока 1 пролетает через точки: плавная кривая через места и вторая через цели, `fov` / `roll` между ними, за `duration` секунд (по умолчанию 10), `ease` = `"inout"` (по умолчанию), `"in"`, `"out"`, `"linear"`, переходя от камеры игры за `blend` секунд. Потом остаётся в последней точке. Не больше 16 точек; `rc.camera(...)` или `rc.cameraPath(nil)` завершают; заканчивается вместе с гонкой |

Туман, солнце, свет, вода и камера режима остаются на его финальном экране (обычная гонка сбрасывает их на финише);
они сбрасываются при выходе из гонки, при *Ещё раз* и при перезагрузке. *Ещё раз* (на странице результатов, рестарт
из меню паузы, сетевое «ещё раз») освобождает всё, как выход из гонки: камеру и её путь, удержание конца, паузу и
замедление, скрытый HUD и его части, захват ввода, облик, звуки и звуковой фон, замены `rc.setCar` (каждая машина
снова своя, со своей окраской и физикой), команды, тексты списка, приказы ИИ, блок возврата, таймеры и сообщения; затем
режим начинается заново (`onModeLoad`, `onModeStart`). Пока режим держит музыку гонки беззвучной
(`rc.levelAmbient(false, -100)`), музыка страницы результатов тоже молчит, чтобы был слышен собственный финальный звук
режима; музыка возвращается при выходе из гонки. Звуковые файлы: `.wav` (PCM или Microsoft ADPCM), `.ogg`, `.mp3`,
`.au`.

### Сетевые гонки (1.5)

Режимы работают и в сетевой гонке. Хост выбирает режим в лобби командой чата `/mode <id>` (`/mode` показывает
список, `/mode race` возвращает обычную гонку); мод режима нужен каждому игроку. В гонке **скрипт режима работает на
каждой машине, но решает только скрипт хоста**:

| Вызов / событие | Что делает |
|---|---|
| `rc.mode.host()` | `true` на машине, чей скрипт решает: всегда в одиночной игре, в сети только на хосте |
| `rc.mode.send(name, ...)` | решающий скрипт сообщает решение: `onModeEvent(name, ...)` вызывается здесь сразу, а на клиентах при получении сообщения. Значения: `nil`, логические, числа, строки (не более 32, 1000 байт). На клиенте ничего не делает и возвращает `false` |
| `onModeEvent(name, ...)` | меняйте раунд здесь (`rc.setCar`, `rc.setCarTeam`, `rc.mode.freeze` / `listText` / `message` / `timer` / `finish` ...), чтобы все машины делали одни и те же вызовы |
| `onModeLoad(info)` / `onModeStart(info)` | `info.network` (сетевая гонка) и `info.host` (решает эта машина) |

- Решайте только там, где `rc.mode.host()` истинно (`onCollision`, `onModeTimer`, проверки в `onModeFrame`), а время
  или случайный выбор передавайте в сообщении, не вычисляйте заново на каждой машине.
- `onCollision` на хосте получает и касания, о которых клиенты сообщают для своих машин; `onRespawnBlocked` работает
  только на хосте (клиент сообщает о своей машине); `rc.mode.respawnCar(car)` на хосте возвращает машину другого
  игрока через его компьютер.
- `rc.options`: настройка с `perPlayer = true` (вид, звук) остаётся у каждого своя; у остальных во время гонки на всех
  машинах действует значение хоста (`rc.setting`).
- В сетевой гонке нет машин ИИ (`rc.ai` возвращает `false`), `rc.setCar` меняет физику только своей машины, а
  возвращённая машина ставится на стартовое место (точки дороги берутся из путей ИИ).

### Пример «Зомби»

`docs\modding\examples\zombies` — игра в салки: после 10 с форы («Беги!») случайная машина (твоя или ИИ) становится
зомби: Warhammer в зелёной камуфляжной окраске, и ездит как он. Зомби, коснувшийся выжившего (контакт машин не слабее
заданной силы), заражает его. Зомби побеждают, когда заражены все; выжившие — когда истекает время (по умолчанию
5:00). Результаты показывают, кто выжил и кто когда заразился. Зомби ИИ гонятся за ближайшим выжившим, до которого
можно доехать по дороге, выжившие ИИ убегают. Над раундом серо-зелёный туман, тем гуще, чем меньше выживших; при
заражении световая панель геймпада зеленеет и он вибрирует; `rc.stats` считает раунды и победы зомби / выжившим.
Вместо списка гонщиков — своя строка состояния (выжившие / зомби, оставшееся время, твоя роль). Страница настроек:
лимит времени (1 .. 10 мин), фора, сила заражения, туман вкл. / плотность, агрессия ИИ-зомби, осторожность
ИИ-выживших, фоновый звук вкл. / громкость, сердцебиение вкл. / дальность, что будет с выпавшим выжившим (станет
зомби / выбывает), через сколько выпавший зомби вернётся на дорогу, финальная камера вкл. / выкл. Все тексты на
четырёх языках. В этом режиме игра не возвращает машины (`respawn = false`): машину на крыше ставит на колёса на
месте. В конце раунда финальная сцена (не в VR): при победе зомби камера поднимается от последней жертвы над
собравшимися зомби, при победе выживших облетает их; въезжает табло (время выживания, кто кого поймал, последний
выживший, итоги, твоё лучшее время выживания из `rc.stats`); её нельзя пропустить, она длится сцену или финальный
звук (не больше 30 с), потом появляется страница результатов. Чтобы играть, скопируйте папку `zombies` в папку `mods`
игры.

Его звуки — собственные файлы автора мода и **не** входят в публичный пример; положите свои в папку `sounds\` мода
(каждый отсутствующий пропускается с предупреждением): `zombie_ambient.mp3` (звуковой фон раунда вместо фона уровня),
`thunder01.wav` (новый зомби, слышен по всей трассе с места события), `zombie_attack*.wav` (заражающий контакт, у обеих
машин), `heart_beat.wav` (твоё сердцебиение со стороны ближайшего зомби, чаще по мере приближения),
`zombie_outro.mp3` (победа зомби), `humans_win.wav` (победа выживших).

## 7. Ограничения песочницы

- Доступно: базовые функции Lua, `table`, `string`, `math`, `utf8`, `coroutine`, а также `os.clock`, `os.time`,
  `os.date`.
- Недоступно: `io`, остальная часть `os`, `require`, `dofile`, `loadfile`, `debug`, `package`, `string.dump`.
- `load` принимает только текстовые фрагменты (строку; без двоичных фрагментов).
- `collectgarbage` принимает только `"count"`.
- Память: 64 МБ на мод.
- Время: `LuaBudget` инструкций Lua на вызов события. Долгая работа внутри одного библиотечного вызова (например,
  огромный `string.rep` или сложный шаблон) по инструкциям не считается; пишите скрипты простыми.
- Скрипты никогда не пишут файлы игры, файлы модов или сохранения игроков; записываются только файлы настроек и
  статистики мода.

## 8. Обработка ошибок

- Ошибка загрузки, ошибка выполнения или превышение бюджета прерывают только этот вызов. Игра продолжается.
- Каждая ошибка записывается в `game_dbg.log` как `Lua [mod] что: файл:строка: сообщение` (со стеком вызовов).
- После 5 ошибок скрипты мода выключаются («mod scripts disabled after repeated errors»). Исправьте скрипт и
  нажмите «Применить» на экране «Моды» (или сохраните файл в режиме разработчика, см. ниже).
- Вызов, использовавший больше 80 % бюджета, даёт одно предупреждение.

## 9. Режим разработчика (`RcCarsRe.exe -dev`)

- Ошибки и предупреждения показываются в окне консоли: строки ошибок красные, предупреждения жёлтые (и Lua, и
  игры); ошибки также появляются в красной полосе в игре.
- Команда консоли `lua` перечисляет моды со скриптами; `lua <код>` выполняет код в состоянии последнего загруженного
  мода, `lua <mod> <код>` — в состоянии этого мода, и печатает результаты (работает и выражение, например
  `lua rc.race().state`).
- Горячая перезагрузка: файлы `.lua` модов-папок проверяются раз в секунду; если один изменился, скрипты этого мода
  загружаются заново (zip-моды: «Применить»). Перезагрузка также отменяет все замены камеры, погоды и световой панели.

## 10. Примеры

В `docs/modding/examples/` четыре готовых мода. Скопируйте папку в `mods\` рядом с `RcCarsRe.exe`:

- `laptime_hud`: время гонки игрока 1 (то же, что таймер HUD), текущий, прошлый и лучший круг в рамке, в формате
  времени игры; параметры: лучший круг, размер, угол.
- `checkpoint_sound`: на каждой контрольной точке игрока 1 играет собственный `sounds\ding.wav` мода и мигает её номер.
- `drift_air`: когда машина игрока 1 приземляется после прыжка, показывает время в воздухе, даёт короткую вибрацию
  и вспышку световой панели и хранит через `rc.stats` лучшее время в воздухе по трассам и число прыжков.
- `photo_mode`: фоторежим (P или кнопка Back / Share / Create геймпада): гонка на паузе, HUD скрыт, свободная камера, F12 / A — снимок, rc.stats считает их (API 1.2).
- `zombies`: игровой режим (API 1.4): салки / заражение против ИИ, см. «Игровые режимы».

Минимальный скрипт:

```lua
function onLap(car, lap, t)
  local p = rc.player(1)
  if p and p.index == car then rc.log("lap " .. lap .. ": " .. rc.formatTime(t)) end
end

function onLand(car, air)
  local p = rc.player(1)
  if p and p.index == car and air > 0.5 then
    rc.rumble(0.6, 0.2)
    rc.stats.add("jumps")
  end
end

function onFrame(dt)
  if rc.race().state == "racing" then
    rc.hudText(400, 20, "Hello from Lua", 0xffffff40, 1, "center")
  end
end
```

## 11. Решение проблем

| Проблема | Проверьте |
|---|---|
| Ничего не происходит | `LuaScripts=1` и `Mods=1` в `RcCarsRe.ini`; мод включён на экране «Моды»; файл лежит в корне мода или в `scripts\`; в `game_dbg.log` есть `Lua [mod]: ... loaded` |
| «mod scripts disabled after repeated errors» | прочитайте первые строки ошибок `Lua [mod]` в `game_dbg.log`, исправьте скрипт, нажмите «Применить» |
| «instruction budget exceeded» | событие сделало слишком много работы за раз; разделите её на кадры или увеличьте `LuaBudget` |
| Элемент HUD не виден | вызовы HUD действуют один кадр: вызывайте их из `onFrame`; проверьте байт альфы цвета (`0xFF......` — непрозрачный) |
| «texture ... not found» / «sound ... not found» (жёлтые) | имя и папка файла в моде; картинки PNG, DDS или CSI; звуки WAV, OGG, MP3 или AU |
| В тексте `?` | пишите скрипт в UTF-8; в шрифте игры есть только символы кодовой страницы её языка |
| Время первого круга меньше таймера HUD | как в игре, время круга считается от линии старта/финиша; время гонки — `rc.race().time` |
| Камера не меняется | только в гонке, только вид игрока 1, не в VR |
| Нет вибрации / световой панели | нужен подключённый геймпад; `Rumble`, `LightBar`, `AdaptiveTriggers` в `RcCarsRe.ini`; вибрация и курки действуют только во время езды в гонке |
| Ошибки в консоли -dev | строки ошибок красные, предупреждения жёлтые; те же строки есть в `game_dbg.log` |
