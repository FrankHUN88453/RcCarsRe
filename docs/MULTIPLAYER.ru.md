# Сетевая игра в RcCarsRe

[English](MULTIPLAYER.md) | [Magyar](MULTIPLAYER.hu.md) | **Русский** | [Polski](MULTIPLAYER.pl.md)

RcCarsRe (пересобранный exe RC Cars) играет в сетевую игру оригинала (Главное меню > Multiplayer > Create game /
Join game) по собственному протоколу UDP. С оригинальным RCCARS.exe он не совместим, DirectPlay не нужен.
Гоняются до 6 игроков; хост ведёт игру (трасса, круги, старт, таблица гонки).

## Создание игры в локальной сети

1. Главное меню > Multiplayer > **Create game**. На странице Network options задайте имя игры, макс. задержку,
   скорость соединения (от неё зависит, как часто передаются состояния машин) и число игроков. Поле "Port" можно
   оставить пустым (по умолчанию `NetPort`, 2302).
2. **Create**. Вы в лобби ("Wait players"). На странице Race summary выберите трассу и круги.
3. Когда все остальные нажали **Ready**, нажмите **Race**.

При первой игре в локальной сети Windows может спросить, можно ли RcCarsRe пользоваться сетью: разрешите для
частных сетей. С `NetBind=loopback` всё остаётся на этом ПК, и Windows не спрашивает.

## Подключение

- Главное меню > Multiplayer > **Join game**. Список сразу и каждую секунду ищет игры в локальной сети (и копии на
  этом ПК); идущая гонка или игра с задержкой выше её максимума не показывается. **Sort** меняет порядок.
- **Прямой IP:** введите адрес хоста в "Server name" (например `192.168.1.20` или `192.168.1.20:2302`), порт в
  "Port", если он не стандартный, и нажмите **Search**.
- Выберите строку, **Connect**, затем **Ready** в лобби.

## Ваша машина (лобби: Car setup, Car restrictions)

- **Car setup**: ваша машина, бустер, двигатель и шины (вращающаяся машина их показывает) и **Next skin**. Ваш
  выбор все видят в таблице Race summary и в гонке.
- **Car restrictions**: хост разрешает или запрещает каждую машину и задаёт её максимальное улучшение (Default,
  Level 1 .. 3). Остальные видят правила, но не могут их менять. Выбор вне правил возвращается к ближайшему
  разрешённому; пока ваша машина нарушает правила, **Ready** не принимается.
- В оригинальной игре на странице Car setup меняется только раскраска (машина сбрасывается на Road Rage).
  `NetCarChoice=0` возвращает это поведение.

## Игра через Интернет

Наш сервер не нужен: один игрок создаёт игру, остальные подключаются к его интернет-адресу.

1. **UPnP (автоматически).** Если вы создаёте игру с `NetBind=any`, RcCarsRe просит роутер открыть игровой UDP-порт
   (`NetUPnP=1`). Через несколько секунд в лобби появляется золотая строка: `Internet: 1.2.3.4:2302 (UPnP)` - этот
   адрес дайте друзьям. Если написано `UPnP not available: forward UDP 2302 by hand`, на роутере выключен UPnP (или
   вы за вторым роутером / NAT провайдера).
2. **Проброс порта (вручную).** В роутере пробросьте **UDP**-порт 2302 (или ваш `NetPort`) на локальный адрес этого
   ПК. Ваш интернет-адрес покажет роутер или любая страница "мой IP".
3. **Подключение:** Join game > интернет-адрес хоста в "Server name" (`1.2.3.4` или `1.2.3.4:2302`) > **Search** >
   **Connect**.
4. **Приглашение через Discord.** При `Discord=1` и `NetDiscordJoin=1` ваш профиль Discord показывает игру, пока вы
   хост или в игре, с кнопками **Join** / **Ask to join** для друзей (у них тоже должны быть RcCarsRe и Discord).
   Подключение из Discord открывает Multiplayer > Join game с адресом и подключается. Если RcCarsRe не запущена,
   Discord запускает её (для этого RcCarsRe записывает свою команду запуска в
   `HKCU\Software\Classes\discord-<DiscordAppId>`). "Ask to join" принимается сразу (`NetDiscordAutoAccept=1`); при `0`
   в лобби появляется вопрос Да / Нет.

Ключ подключения, который Discord передаёт друзьям, содержит ваш интернет- (или локальный) адрес и порт - его видят
только те, кого вы впускаете. Windows может один раз спросить, можно ли RcCarsRe использовать сеть: разрешите для
сетей, в которых вы играете.

## Мир в сетевой гонке

Жизнью трассы управляет хост, и все видят то, что у хоста: транспорт (грузовики, Hummer и БТР выезжают, когда их
отправляет хост, и едут одним путём на каждом ПК; башня БТР поворачивается как у хоста), людей, собак и охранников (где
они стоят и ходят, их анимацию и есть ли они вообще), крабов (где и когда краб вылезает из норы), банки, мячи и другие
предметы (их положение и вращение), а также очереди охранников и башни (выстрелы и попадания в вашу машину). Предмет,
который вы толкнули на своём ПК, сдвигается и у хоста. Копии у остальных следуют за хостом с небольшой задержкой (люди
примерно на 0,3 с). Чаек, пауков и стервятников оригинал не передаёт: каждый ПК ведёт своих. При самой медленной
настройке соединения (bpsLevel 0) оригинал не передаёт ни людей, ни собак, ни охранников, ни предметы, ни башню; для
предметов нужен bpsLevel 2 или выше.

## Две копии на одном ПК (для проверки)

    cd /d D:\Games\RcCars
    start "" D:\Games\RcCars\_re\rebuild\out\RcCarsRe.exe -novid -instance 1
    start "" D:\Games\RcCars\_re\rebuild\out\RcCarsRe.exe -novid -instance 2

`-instance N` разрешает несколько копий: у каждой свой порт (NetPort + N - 1), журнал `game_dbg_N.log`, настройки
окна `RcCarsRe.instN.ini` (окно 960 x 540; Display / Width / Height / WindowX / WindowY / PlayerName) и копия
сохранений `Saves\Instance<N>\` (настоящие сохранения только читаются). Начиная со 2-й копии имя "<профиль> N", если
PlayerName не задан. Копия 1 - хост, копия 2 подключается к `127.0.0.1`.

## Имена

- `[Modern] PlayerName=` - ваше имя в гонках, результатах, таблицах и в сетевой игре (не более 10 букв; пусто = имя
  профиля). `PlayerName2=` - для 2-го игрока разделённого экрана. Это только отображаемые имена: они никогда не
  записываются в профиль, RCCars.crs или файл призрака.
- `[Modern] NetSessionName=` - имя игры, которую вы создаёте (пусто = имя со страницы Create game).

## Чат

- Лобби: строка чата страницы Race summary и страница **Chat**.
- Гонка: **Z** (`ChatKey`) открывает строку под чатом гонки (подсказка «Нажмите Z, чтобы написать в чат...» показывает где), **Enter** отправляет, **Esc** отменяет. Пока вы
  печатаете, клавиатура не управляет машиной (гонка идёт дальше). **Y** снова показывает последние строки. (В
  оригинале ввода в гонке нет; это новое.)

## Команды

Вводите их в чат через `/`. Хост может вводить их и в консоль -dev без `/`.

| Команда | Кто | |
|---|---|---|
| `/help`, `/players` | все | команды; номер (#n), пинг и короткие id каждого игрока |
| `/kick <имя или #n> [причина]` | хост | удаляет игрока (он видит причину) |
| `/ban <имя или #n> [причина]` | хост | удаляет игрока и не пускает обратно |
| `/unban <имя, строка или id>` | хост | имя, строка `/bans` или 8+ hex-цифр id; при нескольких совпадениях `/unban <x> all` |
| `/bans` | хост | баны |
| `/say <текст>` | хост | строка "[SERVER] " всем (также из консоли -dev хоста: `say ...`) |
| `/map <трасса>`, `/laps <n>` | хост | трасса следующей гонки (beach_1 .., имя из меню или 1 .. 10) и круги |
| `/mode [id]` | хост | игровой режим следующей гонки из мода (например `/mode zombies`); `/mode` показывает список, `/mode race` обычная гонка. Только в лобби; мод нужен каждому игроку |
| `/votekick <имя или #n> [причина]`, `/votemap <трасса>`, `/voterestart` | все | начать голосование (для votekick нужно `NetVoteKickMin` игроков вместе с хостом; цель не голосует) |
| `/yes`, `/no` (в гонке **F1** / **F2**) | все | ответ на голосование |
| `/cancelvote` | хост | завершает голосование |

Голосование проходит, если «за» больше половины игроков (начавший считается «за»); оно кончается через
`NetVoteTime` секунд; игрок может начинать голосование раз в `NetVoteCooldown` секунд; одновременно идёт одно.
Принятое голосование за трассу задаёт трассу следующей гонки; перезапуск - это "Race again" оригинала.

Имя хоста показывается как «[HOST] <имя>» в лобби, списке гонки, результатах, его строках чата и в /players.
Причина кика / бана (до 64 символов, иначе «no reason given») видна игроку, всем в строке сервера, и хранится в
bans.txt и журнале чата.

## Баны и что передаётся

При подключении каждый клиент передаёт: имя, случайный id установки (`NetClientId.txt`) и два **хэшированных
отпечатка оборудования** (SHA-256 от MAC-адресов физических сетевых адаптеров вместе с серийным номером системного
тома и GUID машины Windows, и от одних MAC-адресов). Сырые MAC-адреса и серийные номера никогда не покидают ПК и
нигде не хранятся; хэши используются только для банов. Подключение без верных id отклоняется.

Хост хранит баны в `bans.txt` рядом с exe (`bans_inst<N>.txt` для `-instance N`): по одному в строке, через TAB
(время, имя, id клиента, hwid, macid, адрес, причина), комментарии `#`; файл можно править вручную, пока игра не
создана. Подключение отклоняется, если совпал id клиента, hwid, macid или адрес.

## Журнал чата (хост)

При `NetChatLog=1` (по умолчанию) хост пишет каждую строку чата, команду, голосование, вход / выход / кик / бан и
начало / конец игры со временем в `Logs\chat_<дата>.log` (`chat_<дата>_inst<N>.log`). В нём имена и короткие id,
адресов нет. Клиенты журнал не пишут.

## Ключи RcCarsRe.ini ([Modern])

| Ключ | По умолчанию | |
|---|---|---|
| `PlayerName`, `PlayerName2` | пусто | отображаемые имена |
| `NetSessionName` | пусто | имя создаваемой игры |
| `NetPort` | 2302 | UDP-порт хоста |
| `NetDiscoveryPort` | 2301 | порт списка в локальной сети |
| `NetBind` | any | `any`, `loopback` (только этот ПК) или локальный адрес |
| `NetChatLog` | 1 | журнал чата хоста |
| `NetVotes`, `NetVoteKick`, `NetVoteMap` | 1 | голосования вкл. / выкл. |
| `NetVoteTime`, `NetVoteCooldown` | 30, 60 | секунды |
| `NetVoteKickMin` | 4 | игроков для votekick |
| `ChatKey` | Z | клавиша чата в гонке (буква, цифра, F1 .. F12, Enter, Tab) |
| `NetCarChoice` | 1 | на странице Car setup выбираются машина и детали (0 = как в оригинале: только раскраска) |
| `NetUPnP` | 1 | хост открывает свой порт на роутере через UPnP |
| `NetDiscordJoin` | 1 | Join / Ask to join через Discord (нужен `Discord=1`) |
| `NetDiscordAutoAccept` | 1 | "Ask to join" принимается сразу (0 = вопрос Да / Нет) |

Пока нет: интернет-списка серверов, страниц оригинала Player info / Server info (имя и цвет чата берутся из
профиля / `PlayerName`).
